# Contributing to SmartGiaoAn

We welcome contributions from developers, educators, and language enthusiasts! Here's how you can help:

## Reporting Issues
- Open an issue on GitHub for bugs, feature requests, or documentation improvements
- Include detailed steps to reproduce and expected behavior

## Submitting Pull Requests
1. Fork the repository
2. Create a new branch (`git checkout -b feature/your-feature`)
3. Make your changes and commit (`git commit -am 'Add some feature'`)
4. Push to the branch (`git push origin feature/your-feature`)
5. Open a pull request

## Contributing Content
- Add new worksheets following the CEFR framework
- Improve existing content with Vietnamese localization
- Add translations for English/Vietnamese content
- Create new design assets following the design guidelines

## Code of Conduct
Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) when contributing.
